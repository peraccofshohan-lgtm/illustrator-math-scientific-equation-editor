# User Guide

## 1. The window
- **Toolbar:**
  - New, Undo and Redo.
  - **Insert as** mode.
  - **Insert Equation** (or **Update Equation** while you are editing an existing equation) and **Insert as New**.
  - Save to Library and Show Source.
- **Tabs** (the editing tools, described below).
- **Live Preview:**
  - Generated by the same layout engine that produces the Illustrator artwork.
  - **−/+** zoom, **Fit** and **Refresh** (F5).
  - Click any part of the equation to select it.
  - Empty slots are shown as dotted boxes.
- **Status bar:** shows the result of every action and any errors.

## 2. Ways to build an equation
### Direct Input
Type LaTeX-style syntax. With **Live update** on, the equation updates while you type whenever the text is valid. Errors show the line and column, with a caret (`^`) under the position.

| You type | Result |
|---|---|
| `\frac{a}{b}`, `\dfrac`, `\tfrac`, `\cfrac` | fractions |
| `\sqrt{x}`, `\sqrt[3]{x}` | roots |
| `x^{2}`, `x_{i}`, `x_i^2`, `\prescript{14}{6}{C}` | scripts |
| `\sum_{i=1}^{n}`, `\prod`, `\int_a^b`, `\iint`, `\iiint`, `\oint`, `\oiint` | large operators |
| `\lim_{x\to 0}`, `\max`, `\sin`, `\log_2` | functions and limits |
| `\left( … \right)`, `\left. … \right|`, `\middle|`, `\abs{x}`, `\norm{v}` | stretchy delimiters |
| `\begin{pmatrix} a & b \\ c & d \end{pmatrix}` (also `matrix`, `bmatrix`, `Bmatrix`, `vmatrix`, `Vmatrix`, `smallmatrix`, `array`) | matrices and determinants |
| `\begin{cases} … \end{cases}` | piecewise functions |
| `\begin{aligned} a &= b \\ &= c \end{aligned}`, or just `a &= b \\ c &= d` | multiline equations |
| `\vec{F}`, `\hat{x}`, `\bar{x}`, `\dot{x}`, `\overline{AB}`, `\overbrace{…}^{n}` | accents and braces |
| `\mathbf`, `\mathrm`, `\mathbb`, `\mathcal`, `\mathfrak`, `\text{…}` | font styles and text |
| `\dv{f}{x}`, `\pdv{f}{x}`, `\pdv[2]{f}{x}`, `\bra{\psi}`, `\ket{\phi}` | physics notation |
| `\unit{kg.m/s^2}`, `\sci{6.022}{23}` | units and scientific notation |
| `\ce{2H2 + O2 -> 2H2O}` | chemistry |
| `\color{red}{x}`, `\style{color=#0055AA;bold;scale=1.2}{x}` | colour and per-element style |

Input options:
- **Smart operators** turns `<=`, `>=`, `!=`, `->`, `=>`, `<=>`, `+-` and `...` into proper symbols.
- **Recognize functions** treats `sin`, `cos`, `log` and similar names as functions without a backslash.
- **Auto-size brackets** makes `( )`, `[ ]` and `{ }` stretch with their content.

### Symbols
Search by name, character, command or keyword, or filter by category. Double-click a symbol, or press **Insert Symbol**. The details panel shows the Unicode code point, the syntax, and the font coverage. You can add symbols to **Favorites**.

### Equation Builder
- **Insert Structure:** fractions, roots, scripts, brackets, sums, integrals, limits, derivatives (pick the function, variable and order), matrices (pick rows, columns and type), piecewise functions, and aligned equations.
- **Selected Element:** select an element in the structure tree or in the preview. You can then:
  - Edit its syntax and press **Apply**.
  - Delete, Duplicate or Move it, or select its parent.
  - **Wrap** it in another structure.
  - Toggle optional slots (super/subscript, root index, limits, label).
  - Change the limits position.
  - For matrices and multiline equations: add or delete rows, columns or lines, change the matrix type, add a tag.
- **Chemistry:** balance reactions, compute molar masses, and look up elements (see section 4).

New content goes **into** the selected empty slot, or **after** the selected element. If nothing is selected, it goes at the end.

### Templates
383 ready-made formulas covering mathematics, physics, chemistry and units. **Use Template** replaces the current equation; **Insert at Selection** inserts it. You can save the current equation as **My template**.

## 3. Inserting into Illustrator
| Mode | Result | Re-editable |
|---|---|---|
| Editable group (default) | One group named `Equation: …`, containing text frames (glyphs) and paths (bars, radicals, brackets, arrows) | Yes |
| Separate components | The same objects, without a group | No |
| Single text object | One text frame. Only possible when the expression has an exact linear Unicode form, such as `E = mc²` | Yes |
| Outlined artwork | Text converted to outlines; asks for confirmation first | Yes (source is kept in the note), but not as text |

By default the equation is placed at the centre of the current view; **Settings** can change this to the centre of the artboard.

Before inserting, the editor checks that a document is open and that the active layer (and its parent layers) is neither locked nor hidden. If anything fails while inserting, every object created so far is removed.

### Re-editing
1. Select the equation group, or any object inside it.
2. Run the script. The equation and its formatting are loaded automatically.
3. Make your changes and press **Update Equation**. The new version replaces the old one at the same baseline position, even if you moved the group. **Insert as New** keeps the original.

## 4. Chemistry
Type a reaction in **Equation Builder › Chemistry**:
- Arrows: `->`, `<-`, `<=>` and `<->`. Conditions go in brackets, as in `->[heat]` or `->[Fe][500 K]`.
- Charges: `^2+` or a trailing `+`/`-`. Electrons: `e^-`.
- States: `(s)`, `(l)`, `(g)` and `(aq)`. Hydrates use `.`, as in `CuSO4.5H2O`.

**Balance** finds the smallest integer coefficients using exact rational arithmetic, then verifies every element and the total charge. Reactions that have no balance, or more than one independent balance, are reported rather than guessed.

## 5. Formatting
- **Equation formatting:**
  - Math and text font, size, colour, bold.
  - Italic variables and italic lowercase Greek.
  - Display style.
  - Spacing, fraction bar thickness, stroke width, fraction gap.
  - Script scales and offsets.
  - Matrix row and column gaps, line gap, operator sizes, box padding.
  - Multiline alignment.
  - Presets.
- Invalid values are rejected; the message names the field and its allowed range.
- **Selected element:** colour, bold, italic, scale, baseline shift and font for one element. **Clear** removes them.
- **Fonts:** shows which of the recommended math fonts are installed. A missing font produces a warning and an automatic fallback.

## 6. Library, Favorites, Recent
- **Formula Library:** save, load, overwrite, duplicate, rename (with category), delete (with confirmation), favorite, and insert into the current equation.
- **Search** covers names, categories, tags and content.
- **Import/Export:** a versioned JSON file. On import, duplicates are skipped, name clashes are renamed, and invalid entries are listed with a reason. Imported data is never executed.
- **Favorites** and **Recent** keep formulas and symbols one click away.

## 7. Keyboard shortcuts
| Keys | Action |
|---|---|
| Ctrl/Cmd+Enter | Insert / Update |
| Ctrl/Cmd+S | Save to library |
| Ctrl/Cmd+Z | Undo (when focus is not in a text field) |
| Ctrl/Cmd+Y or Ctrl/Cmd+Shift+Z | Redo (when focus is not in a text field) |
| Ctrl/Cmd+N | New equation |
| F5 | Refresh preview |
| Esc | Close |

Inside text fields, Ctrl+Z belongs to the text field itself; this is a ScriptUI limitation. Shortcut delivery depends on the operating system and Illustrator version, and is not tested.
