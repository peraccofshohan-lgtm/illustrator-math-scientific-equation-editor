## What these tests do and do not prove

- **Tested (automated, in Node.js):** the parser, serializer, AST, structural editor, semantics, chemistry engine, layout engine, formatting model, font resolution logic, persistence (with a real file system behind an ExtendScript `File`/`Folder` mock), the ScriptUI dialog wiring (against a ScriptUI mock), and the renderer's calls into a mock of the Illustrator DOM (object creation, naming, notes, placement, rollback).
- **ES3 runtime check:** one suite runs the complete release script in a sandbox from which every ES5+ built-in (`Array.prototype.indexOf/map/forEach`, `JSON`, `Object.keys`, `String.prototype.trim`, `Date.now`, ...) has been deleted, emulating ExtendScript's ES3 library. The build also parses the asset with an ES3 parser (acorn, `ecmaVersion: 3`).
- **Not tested:** the script has **not been run inside Adobe Illustrator** (no Illustrator installation was available). Actual on-screen ScriptUI appearance, real font measurement, real text rendering, `createOutline()`, file dialogs and keyboard event delivery are therefore **Not tested**. Mocks verify the script's logic, not Illustrator's behaviour.

## Defects found and fixed by these tests

Each has a regression test in `tests/regression-tests/regression.test.js`:

- R5/R6: parsing and serialising long input was quadratic (20 000 characters took > 20 s); now linear.
- R7: `U.toNumber` returned `undefined` for invalid input, so invalid stored font sizes became NaN; now returns `null` and falls back to defaults.
- R8: CMYK colour conversion was called with the wrong arguments (colours in CMYK documents would have been empty).
- R9: re-importing the same library file duplicated items renamed during the first import.
- R12: nested superscripts had exponential layout cost (22 levels took 1.7 s, 40 levels would never finish); now linear.
- R13: the node limit rejected the largest matrix the builder can create (100 × 100).
- Also fixed: equation update shifted the equation by a few points (now preserves the baseline origin, even after the user moved it), list selection was lost after Rename, and tabs were selected by index (ScriptUI expects the tab object).
