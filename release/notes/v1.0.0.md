A single-file ExtendScript (`.jsx`) equation editor for Adobe Illustrator. You build equations visually, from templates, or by typing LaTeX-style syntax, and the script inserts them as native, editable Illustrator artwork: text frames, vector paths, and a named group that you can re-edit later.

## Download
**`Shohan_Khan_Illustrator_Math_Scientific_Equation_Editor.jsx`** (below, 474,525 bytes). This one file is all you need; it has no dependencies.

SHA-256: `a4b12b8dfb8786f95122186e473b3518aa1efd8f88720194c5f0a741196ea353`

## Installation
- **Run once:** in Illustrator, choose **File › Scripts › Other Script…** and select the file.
- **Permanent:** copy the file to `Adobe Illustrator <version>/Presets/<locale>/Scripts/` and restart Illustrator. It then appears under **File › Scripts**.

Details: [INSTALLATION](https://github.com/peraccofshohan-lgtm/illustrator-math-scientific-equation-editor/blob/v1.0.0/docs/INSTALLATION.md)

## Features
- **11 tabs:** Home, Symbols, Equation Builder, Direct Input, Templates, Formula Library, Favorites, Recent, Formatting, Settings, Help/About. Plus a toolbar, a live preview (zoom, fit, refresh, click-to-select), a status bar, tooltips and confirmations.
- **Direct Input:** LaTeX-style syntax with line and column error reporting. It shares a single AST with the **visual Equation Builder**, so the two stay in sync both ways.
- **Structures:**
  - fractions, roots, scripts and prescripts
  - matrices and determinants (up to 100×100), vectors
  - integrals (single to volume, contour, surface), sums, products, limits, derivatives
  - piecewise functions, aligned multiline equations, accents and braces
  - units, scientific notation, bra-ket notation
- **743 symbols** in 30 categories (mathematics, physics, SI units, chemistry) and **383 templates** in 17 categories.
- **Chemistry:**
  - `\ce{…}` notation and all 118 elements
  - charges, isotopes, states and hydrates
  - reaction arrows with conditions
  - **exact balancing** with atom- and charge-count verification
  - molar mass
- **Insertion modes:** editable group (default), separate components, single text object (simple expressions), outlined artwork (asks for confirmation, never the default).
  - Checks for a missing document and for locked or hidden layers.
  - Rolls back completely on failure.
  - **Re-edit:** select an equation, run the script, then press Update. The baseline position is kept.
- **Formatting:** fonts with math-font detection and recommendations (STIX Two Math, Cambria Math, Latin Modern Math), missing-font warnings, size, colour, bold/italic, spacing, bar thickness, script scale and offsets, matrix spacing, presets, per-element overrides.
- **Library:** save, load, duplicate, rename, delete, favorite, search, custom templates, recent and favorite symbols. Versioned JSON import/export that is parsed strictly and never executed.
- Undo/redo with bounded history, plus keyboard shortcuts (Ctrl/Cmd+Enter, Ctrl/Cmd+S, Ctrl/Cmd+Z/Y, Ctrl/Cmd+N, F5, Esc).

## Compatibility
- **Target:** Illustrator CC 2015 (19) and later, on Windows and macOS.
- **No Illustrator version has been tested.** The script was developed without access to Illustrator, so every version is classified as *expected compatible, untested*.
- The release file is verified to be ECMAScript 3 in two ways:
  - an ES3 parser check
  - a full run with all ES5 built-ins removed

Details: [COMPATIBILITY](https://github.com/peraccofshohan-lgtm/illustrator-math-scientific-equation-editor/blob/v1.0.0/docs/COMPATIBILITY.md)

## Testing
All **138 of 138 automated tests pass**. They ran in Node.js here and again on GitHub Actions before this release was published. They cover:
- parser and structure
- layout
- physics and chemistry
- formatting and persistence
- the UI (ScriptUI mock) and the renderer (Illustrator DOM mock)
- an ES3 runtime emulation
- 13 regression tests and the mandatory extreme tests A–H:
  - 40-level nesting
  - 100×100 matrices
  - 2000-term and 300-line equations
  - fuzzing
  - Unicode
  - hard redox and organic reactions
  - a hostile 6000-item import
  - 1000 random edits with undo/redo

Mocks verify the script's logic, not Illustrator's behaviour. The following are **not tested**: on-screen appearance, real font measurement, outlines, file dialogs and shortcut delivery. Details: [TEST_REPORT](https://github.com/peraccofshohan-lgtm/illustrator-math-scientific-equation-editor/blob/v1.0.0/docs/TEST_REPORT.md)

## Known limitations
- Not yet run in Adobe Illustrator (see Compatibility).
- Glyph heights come from proportional tables. Advance widths are measured from your fonts inside Illustrator, so spacing in the preview can differ slightly from the inserted artwork.
- Plain-text conversion (used for names and Unicode output) simplifies some constructs:
  - `\log_2 x` becomes `log ₂x`
  - the lower label of `\xrightarrow[below]{above}` is dropped
  - `a &= b` becomes `a & =b`
- Single-text mode only works for expressions with an exact linear Unicode form.
- Inside text fields, Ctrl+Z undoes typing rather than the equation (a ScriptUI limitation).
- Limits:
  - 100,000 characters of input
  - 60,000 structure nodes
  - nesting depth of about 120
